# تدريس — منصة تعليمية متكاملة

## التشغيل
```bash
cp .env.example .env   # املأ المفاتيح
docker compose up -d   # postgres + redis
npm install
npx prisma migrate dev --name init
npm run db:seed
npm run dev            # http://localhost:3000
npm test               # اختبارات الوحدات الحرجة
```

## النشر
- Vercel/Node + PostgreSQL مدار (Neon/Supabase) + Redis (Upstash) + S3.
- `prisma migrate deploy` عند النشر، و`CRON_SECRET` لمهام التذكير.
- Worker الإشعارات: شغّل `tsx src/lib/worker.ts` أو خدمة منفصلة مع `startWorker()`.

## ما يحتاج مفاتيح/إعدادات منك
| البند | المتغير | ملاحظة |
|---|---|---|
| بوابة الدفع المحلية (ذهبية/CCP) | `EDAHABIA_API_KEY/MERCHANT_ID/WEBHOOK_SECRET`, `CCP_GATEWAY_*` | CCP يعمل الآن تحويلاً يدوياً بمراجعة المدير |
| PayPal | `PAYPAL_CLIENT_ID/SECRET/MODE/WEBHOOK_ID` | الاشتراكات الدورية تلقائية |
| Zoom | `ZOOM_ACCOUNT_ID/CLIENT_ID/SECRET/WEBHOOK_SECRET` | يوجد مسار بديل `LIVE_FALLBACK_URL` |
| الرسائل | `RESEND_API_KEY/MAIL_FROM`, `TWILIO_*`, `WHATSAPP_BUSINESS_*` | يعمل تسجيلاً حتى بدون مفاتيح |
| ذكاء اصطناعي | `ANTHROPIC_API_KEY` أو `OPENAI_API_KEY` أو `AI_FREE_ENDPOINT` | الزر المجاني عبر endpoint مجاني |
| التخزين | `S3_*` | تسجيلات وملفات |
| الأسعار | جدول `Plan`/`Setting` + `PLATFORM_FEE_PERCENT` | تُحدَّد لاحقاً من لوحة المدير |

## الافتراضات المسجلة
1. الأسعار لاحقاً: بذرة افتراضية (تجريبية 0 / احترافية 2900 دج) قابلة للتعديل من اللوحة.
2. CCP = تحويل بنكي مع تأكيد يدوي (حالة `MANUAL_REVIEW`) حتى توفير بوابة معتمدة.
3. الذهبية/بريدي موب عبر البوابة المحلية المعتمدة عند توفر بياناتها؛ البنية جاهزة.
4. تجديد الذهبية/CCP يدوي بتذكير قبل 7 أيام + مهلة 7 أيام؛ PayPal تلقائي.
5. اللغة الافتراضية العربية RTL؛ بنية i18n تسمح بلغات لاحقاً.
6. العمل دون اتصال (offline) مؤجل لمرحلة لاحقة.
7. LTI مؤجل لكن `/api/v1` مصمم لاستيعابه.
8. عجلة الهدايا: مرة واحدة افتراضياً، الكوبونات 30 يوماً، والشروط معلنة للمستخدم.
9. التقارير PDF عبر الطباعة/jsPDF من بيانات CSV نفسها.
10. الاختبارات شغّلها بعد `npm install` (البيئة الحالية بدون Node فلم تُشغَّل آلياً).
