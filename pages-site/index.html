النسخة الكاملة للتطبيق

هذه صفحة تعريفية ثابتة. التطبيق الكامل (Next.js + قاعدة بيانات + مصادقة + دفع) يحتاج استضافة تدعم الخادم مثل Vercel — الكود المصدري كامل في هذا المستودع.

  • دورات مباشرة ومسجلة بفصول ودروس ومسارات تعلم
  • اختبارات وواجبات وشهادات برمز تحقق
  • دفع: بطاقة ذهبية / CCP / PayPal + كوبونات + عجلة هدايا
  • ذكاء اصطناعي: مساعد + زر Ask AI + مولد اختبارات

تشغيل النسخة الكاملة

cp .env.example .env → docker compose up -d → npm install → npx prisma migrate dev → npm run dev
